
# Calculadora Web com Python e Flask

**Autor:** João Pedro Pacheco da Motta

## Sobre o projeto

Aplicação web desenvolvida utilizando Python e Flask,
com interface em HTML, CSS e JavaScript.

## Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão

## Tecnologias utilizadas

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Git e GitHub

## Como executar

1. Clone o repositório.
2. Instale as dependências:

   pip install -r requirements.txt

3. Execute a aplicação:

   python app.py

4. Acesse no navegador o endereço:

   http://127.0.0.1:5000
